# Random Forest Market Prediction

Regime-aware stock prediction for AAPL using technical indicators, volatility features, and Random Forest models with backtesting.

## Key ideas

- Momentum (EMA, WMA, ROC, MOM)
- Volume features (VWAP, volume force)
- Volatility (Parkinson and related estimators)
- Regime conditioning and walk-forward style evaluation

## Stack

Python · Jupyter · scikit-learn · pandas · NumPy

## Open

```bash
git clone https://github.com/Ojchavan/random-forest.git
cd random-forest
jupyter notebook
```
